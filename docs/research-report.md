# 研究报告：长上下文模型的「任务类型悬崖」——读取失败的测量、机制与视图响应

> AI-AttentionSettlement · 零预算前期研究 · 2026-09 ～ 2026-10
> 状态：实验电池已结项；下钻回路与 loop 电池未建（见《系统设计》§8 预注册）

**Abstract (EN).** Across 128K–514K-char corpora and four API models, we measure that long-context failure is a **task-type cliff**, not a length cliff: single-fact retrieval stays at 100% while aggregation collapses to ≈0%, replicated across models and robust to full needle-position shuffling. The failure mechanism is **nearest-read-value substitution** — the model emits one already-read value instead of enumerating (content-driven, 89% same-type, disappears when the attractor sentence is deleted). The response that works is not a smarter model but a **settlement layer**: a ~105-char minimal sufficient view makes single-fact 10/10; gathering all instances into a 1.2K-char view lets enumeration happen. All findings are pre-registered, paired-tested (McNemar), and two early length claims were retracted in writing when the data overturned them.

---

## 1. 背景与问题

名义窗口（旗舰普遍 ~1M）、平台默认档（500K 级）与有效注意力之间存在持续差值。测量线盟友（NoLiMa、RULER、SCBench、Context Rot）一致显示：字面匹配型任务撑得最久，聚合/多跳/联想任务最早塌。

本项目问的问题更窄：**失败到底由什么决定——长度、位置，还是任务类型？** 以及：**如果不改模型，外置一层"把该读的推到眼前"能修复多少？**

## 2. 仪器与方法

**语料家族**（全部配 SHA256 与构建脚本，arXiv 衍生语料不直接分发、走 fetch 重建）：

| 语料 | 规模 | 用途 |

**模型**：glm-4.5-air、glm-4.7-flash、DeepSeek（deepseek-flash）、NVIDIA Nemotron 3.5 Super VL（OpenRouter 免费档；早期记录代号 N3.5）。全程免费额度（约百发/天量级），零预算。

## 3. 发现一：任务类型悬崖

硬语料五档 × 两模型（128K 档，散点分布，无统一模板措辞）：

| 档 | 题数 | N3.5 | glm-4.5-air |
|---|---|---|---|
| L0 缺席（问不存在的 id，正确=拒答） | 5 | 4/5 | **0/5** |
| L1 单事实 | 20 | **20/20** | **20/20** |
| L2 阈值计数（真值 6） | 1 | 0/1（答 4） | 0/1（答 7020） |
| L3 全量求和（真值 102,495） | 1 | 0/1（答 3,061） | 0/1（答 3,965） |
| AGG5（5 种聚合问法） | 5 | 0/5 | 1/5 |

**剂量相图**（合成针场，glm-4.7-flash）：剂量 2 处处 100%；密针 16K 90% → 32K 50% → 128K 40%；疏针恢复 80%——塌陷由**剂量 × 长度**联合驱动，不是长度单变量。

**判决：单事实 100%、聚合 ≈0%，跨模型复现；这不是长度悬崖，是任务类型悬崖。**

长度轴的两次反证：(a) 五针长度曲线统一模型后枚举数 1/0/1/0，非单调——"枚举深度随长度单调下降"撤回；(b) 电池 A 的失败与聚合失败是同一机制（单值替换），"16–32K 悬崖是长度效应"撤回。**位置轴的反证**：20/20 针位全部置换后聚合仍 0/5、0/1、0/1——失败对针序稳健，不是位置伪影。

## 4. 发现二：吸引子——就近读值替换（nearest-read-value substitution）

glm-4.5-air 在缺席档固定输出 `9267`。三步判别：

| 步 | 操作 | 结果 |
|---|---|---|
| ① | 问 5 个不存在的 id | 5/5 答 9267（语料真实值，NX-7013） |
| ② | 打乱全部 20 针位 | 仍 5/5 答 9267 |
| ③ | 删掉 9267 那条针 | 变为 9 / 9902 / 9 / 9 / 9，吸引子消失 |

**判定：内容驱动**（读到哪条就挪用哪条的值；删句即消失）。无值可挪时回落到**问句自身**（9902 = 问句 id 回声），而非另造数——替换与回声是两种失败模式。类型驱动：替换 9 次同型 8 次（89%）。

**与聚合失败同源**：聚合格的失败回复是单个已读值（枚举均值 0.0–0.6，满值 5）——枚举根本没发生。缺席替换与聚合失败是**同一机制的两个严重度**。

**法医样本（glm-4.7-flash，128K 密簇电池 A）**：31 次错误、31 次都是单个兄弟值、30 次是同一个 4472、零多值、零垃圾。同档同密的密针簇中，miss 全部落于簇尾 80.6–80.7% 相对位置——**簇尾效应，非密度混杂**。

**格式的干预证据**：同一模型在 YAML 锚档 10/10、无吸引子。**锚密度的两轴测量**：真实语料锚阶梯 L1′（拆标识位）100% / L2a（删题面路径）90% / L2b（删分节头）90%；合成反向臂 散文 40% → 仅键名 40% → 醒目空边界 55% → 边界携带 id 75%。合读：**锚既不必要（拆名不掉点）也不充分（最好 75%，未进 85% 安全区）**——锚密度由此成为 L* 曲面的第四轴（长度 × 密度 × 深度 × 锚）。

## 5. 发现三：一次自我翻案（max_tokens 假失败）

早期"聚合 ≈0%"的读数有一部分是**我们自己造成的**：判分跑批的 `max_tokens=40` 把枚举输出截断，整批聚合题被误判为失败。输出上限提到 1500 后，DeepSeek 在 130K 全档**枚举全部 20 项并正确累加出 102,495**（用 245 个输出 token）。

由此立了一条总则：**任何"模型做不到"的结论，先排除是不是自己的仪器把它掐死的。** 本报告所有"做不到"类读数均按此复核过。

## 6. 发现四：视图预算、单位与换场

**最小充分视图 = 证据行本身。** 独立文档（冷 prefill）、窗口以 gold 行为中心：105 字符 → 10/10；500 / 1,000 / 2,000 字符 → 全对。单事实任务下 2K 视图比所需大近 20 倍。

**在场即充分，精排无增量。** 同一批 CE 选中 span：前置 15/15、居中 15/15、结尾 15/15、打乱 15/15、CE 原序 15/15——排序增量低于 6.7pp 的分辨率。

**标注与换场的分解**（主关口 H₂′，105 格）：

| 对比 | 增量 | McNemar p | 判定 |
|---|---|---|---|
| ⑦ 原文直答 40% → ⑤ 原地高亮 80% | +40pp | **0.031** | 标注增益可确证 |
| ⑤ 高亮 80% → ⑧′ oracle 2K 视图 100% | +20pp | 0.25 | 换场增量未确证 |

**视图修的是枚举，不是算术。** 2×2 实验（同五值，只改几何与送检文本）：散点×全档 1/5 → 聚簇×全档 2/5 → 聚簇×3.1K 视图 3/5——五项全进了加法，错在一位算术。模型能否在这份全量视图上自己完成聚合，是登记在册、尚未跑的判定实验。

**单位规则**（实测反直觉处）：

- 有分节标记（`===== FILE:`）→ 单位=**块**；k8s 上句级 gold 行 recall@5 = **0/30**（BM25 只找得到文件头），块级正确。
- 散文 → 单位=句（BM25 recall@5 = 100%，CE@5 把 top-1 从 60% 拉到 100%）。
- 对话 → 单位=**整回合，绝不拆**：句子拼贴 0/3，连续原文切片 3/3。
- 块级只配当 BM25 粗筛单位（0.01s），不配进 CE：CE 成本按字符走（块级总量反而贵 ~10 倍），且 **CE 有 512 token 硬截断**——超长块的分数只反映块头，实测 3,000 字符块给全量与前 512 token 打分完全相同。

**规模与预算悬崖。** 合成长对话 1.43M token / 5,000 回合：1/8 预算视图 1.1 秒组装、12/12 命中（BM25-only，延迟近线性）。真实对话语料（130,717 token / 119 回合 / 18 题）：r=1.0 / 0.5 / 0.25 全 18/18，r=0.20 掉到 16/18——**相对预算悬崖在 0.25 与 0.20 之间，建议取 1/4**。

## 6·补 发现五：指称也要在场（T3 resolver）

"答案要在场"的对称命题：**指称未具体化，必败**。半合成单跳会话 × 五臂（R0 裸查询 / R1 最近提及 / R2 会话唯一+弃权 / R3 CE / R4 LLM / R5 oracle）：

- 关键格（全指代 × 多候选）上 R1/R2/R3 全部 **0/9**，R4 LLM **4/9**——Wilson 95% CI [18.9%, 73.3%]，上界 73.3% < 预注册可用线 88.9% → **"LLM 是该格可靠解"被整体排除**（McNemar p=0.0625 单侧，只报点估计差）。
- **弃权不算失败的重读**：R2（规则 + 弃权）静默答错 **0**、覆盖率 68%——它不是精度低，是覆盖率低；在"静默错误"这个生产指标上是最优臂。
- 生产决策表：有判别性锚词 → 检索直达；无锚 + 会话唯一 → 规则解析；**无锚 + 多候选 → 问用户**（LLM 可作建议，不得静默作答）。锚歧义格（半锚 × 同型，恰是吸引子主场）未测。

## 6·补2 发现六：真实载体——强塌被排除，保护程度未决

真实 YAML 语料注入 16 个同型兄弟（聚簇于自然邻域）：首轮 13/16 落预注册边缘区 → 补样 10/10，合计 **23/26 = 88.5%，Wilson 95% CI [71.0%, 96.0%]**。三分支判定：

- **强塌（H-吸收强版本）被排除**——裕量仅 2.2pp；**强保护（H-保护强版本）未确证**——差 1.4 题；点估计最优解释 = **部分保护**（探索性）。
- miss 形态：先锚定块尾真值、再沿序列外推（5.7.46 → 47 → 48）——"串号一次、续写两次"的连片失效。
- **密度 × 可判分性互斥**：真实语料的高命中只说明没有可判分的同型密集区（高同型簇是复制品、值也相同）——"安全区"表述已作废，改为 H-吸收 / H-保护两个可区分假设。
- 跨载体（探索性，三处混淆未控）：同剂量散文 40% vs YAML 88.5%（~+48pp，CI 勉强不重叠）。

**判据与一句话定性**：视图判分自 2026-10-20 换轨为 **recall@block**（含 gold 的块进入预算即过；原"块粒度 rank-1"降级为排序质量描述指标——rank-1 本身是比在场更强的排序证据，不得写成"只证明了在场"）。整个电池的定性：**架构被证实，算法被证伪**——分层必要（直答→视图 +60pp）、层内免工程（位置/顺序/排序全无效应）、层必须物化（原地标注 80% < 物化视图 100%）；"怎么选、怎么排"无可测增量。

**两处判别力虚高的警告**：① 聚簇档的 15/15 有"预算吞并"成分——密簇仅 ≈1.2K token，2K 窗口把整个干扰簇连 gold 一起吞下，选择器只需"切到簇附近"；② 题面含 `NX-####` 时检索退化为精确匹配（id 捷径）。真判别力要靠**分散同型 × 去 id 查询**档（硬语料已补散点与措辞混淆；去 id 档在 k8s 真实任务上部分覆盖）。聚簇 15/15 降级的是**归因**（"选择器解决了难题"），不是读数（换场充分性原样成立）。

## 7. 方法纪律（本项目的元产出）

1. **预注册**：判定树四行出口事先锁定；两个"没跑成"的臂（⑥ 构造不可行、⑧ 跑前作废）登记去处，不删史。
2. **书面撤回文化**：两周内两次撤回自己的长度结论（见 §3），保留原文与撤回理由。
3. **覆盖矩阵**：结论必须与矩阵同读；Dots3/DeepSeek 未上新仪器（免费额度与付费纪律）是显式登记的空白，不是被略过的空白。
4. **仪器优先受审**：max_tokens 翻案（§5）之后，"模型做不到"类主张一律先过自己的仪器复核。
5. **配对纪律**：跨格比较先对齐模型（同模型替换曾把非单调曲线伪装成单调）。
6. **可实验性判据**（T3 一役得出）：判断一个部件能否做实验，先问**它的输入能不能被构造**，而不是它是不是一个系统——resolver 曾被误判"实验室造不出来"，实际它是 (会话历史, query) → query 的函数，函数即可离线测。
7. **仪器与构造审计**（2026-10-20 自查）：朴素子串判分改为数字边界匹配（回扫 360 条记录 0 假阳，旧数据不重算）；runner 加 preflight 断言、几何模式强制声明；两条线的干扰几何不对齐（电池单簇 vs 长度轴多簇）已登记，跨线读数不直接比较。

## 8. 局限

- **n 小**：聚合每格 5 题（或 1 题）、吸引子每格 5 题——方向性结论，不是确证性检验；多数格每模型仅跑一次（temp=0）。
- **时效力**：老仪器（128K 单事实）上 N3.5 / DeepSeek / Dots3 全部 22/22 不塌；硬语料上崩的是 GLM 两代。若塌陷是特定世代的性质，本设计对症的可能是一个正在消失的问题——"架构对不对"与"还值不值得做"是两个问题，边界测量因此与干预本身同等重要。
- **模型覆盖**：核心结论完整档位只在 glm-4.5-air；N3.5 两点；Dots3 / DeepSeek 新仪器空白。
- **单轮静态语料为主**：多轮动态会话（原始构想的主场）只有 turns 模式的静态读数。
- **未测部件**：下钻救援回路、loop 电池（见《系统设计》§8）——设计已预注册，工程未建。
